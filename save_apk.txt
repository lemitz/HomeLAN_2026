## Команды:

```powershell

.\homelan-server.exe
```

**Запуск клиента Windows:**
```powershell
cd Z:\Xchat\client
flutter run -d windows
```

**Билд APK:**
```powershell
cd Z:\Xchat\client
flutter build apk --release
```

```
Z:\Xchat\client\build\app\outputs\flutter-apk\app-release.apk
```

## Важно для Android:

В `lib/main.dart` поменяй IP на свой:
```dart
const String serverUrl = 'http://192.168.X.X:8080';
```

Узнать IP:
```powershell
ipconfig
```
