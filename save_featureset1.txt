## Команды

Сервер:
cd Z:\Xchat\server
go build -o homelan-server.exe ./cmd/server
.\homelan-server.exe

Клиент Windows:
cd Z:\Xchat\client
flutter run -d windows

Клиент Android APK:
cd Z:\Xchat\client
flutter build apk --release
