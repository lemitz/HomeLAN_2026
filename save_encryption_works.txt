## Команды

**Сервер:**
```powershell
cd Z:\Xchat\server
go build -o homelan-server.exe ./cmd/server
.\homelan-server.exe
```

**Клиент Windows:**
```powershell
cd Z:\Xchat\client
flutter run -d windows
```

**Клиент Android APK:**
```powershell
cd Z:\Xchat\client
flutter build apk --release
# APK: Z:\Xchat\client\build\app\outputs\flutter-apk\app-release.apk
```

**Очистка данных:**
```powershell
# Windows клиент
Remove-Item -Recurse -Force "$env:APPDATA\com.homelan" -ErrorAction SilentlyContinue
Remove-Item -Recurse -Force "$env:LOCALAPPDATA\com.homelan" -ErrorAction SilentlyContinue
Remove-Item "$env:USERPROFILE\Documents\homelan_client.db" -ErrorAction SilentlyContinue

# Сервер
cd Z:\Xchat\server
Remove-Item -Recurse -Force data
```

## Ключевые фичи v0.4.0

| Фича | Реализация |
|------|------------|
| E2E шифрование | X25519 (ключи) + ChaCha20-Poly1305 (сообщения) |
| Генерация ключей | В изоляте (без лагов UI) |
| Хранение ключей | SharedPreferences (приватный) + сервер (публичный) |
| Удаление чатов | ПКМ на Windows, долгий тап на Android |
| Валидация сессии | При старте проверяет юзера на сервере |
| Полная очистка | Удаляет ключи, сообщения, кэш |
