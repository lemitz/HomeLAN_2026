## Команды

**Запуск сервера:**
```powershell
cd Z:\Xchat\server
.\homelan-server.exe
```

**Билд сервера:**
```powershell
cd Z:\Xchat\server
go build -o homelan-server.exe ./cmd/server
```

**Запуск Windows клиента:**
```powershell
cd Z:\Xchat\client
flutter run -d windows
```

**Билд APK:**
```powershell
cd Z:\Xchat\client
flutter build apk --release
```

**APK путь:**
```
Z:\Xchat\client\build\app\outputs\flutter-apk\app-release.apk
```

**Очистка данных Windows клиента:**
```powershell
Remove-Item -Recurse -Force "$env:APPDATA\com.homelan" -ErrorAction SilentlyContinue
Remove-Item -Recurse -Force "$env:LOCALAPPDATA\com.homelan" -ErrorAction SilentlyContinue
Remove-Item "$env:USERPROFILE\Documents\homelan_client.db" -ErrorAction SilentlyContinue
```

**Очистка базы сервера:**
```powershell
cd Z:\Xchat\server
Remove-Item -Recurse -Force data
```
