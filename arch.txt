## РАЗБОР ФИНАЛЬНОЙ КРИТИКИ

### 1. Windows без камеры — НУЖЕН ФИКС 🔴

Реальная проблема! Стационарный ПК без вебки не сможет завершить 2-QR exchange.

**Фикс:** Text Fallback для второго QR

```
FLOW С FALLBACK:

Телефон (старое устройство) после сканирования QR #1:
┌─────────────────────────────────────┐
│         Scan this QR code           │
│                                     │
│         ┌─────────────┐             │
│         │   QR #2     │             │
│         │             │             │
│         └─────────────┘             │
│                                     │
│  No camera? [Copy as Text]          │  ← NEW!
└─────────────────────────────────────┘

На ПК (новое устройство):
┌─────────────────────────────────────┐
│  Scan QR from old device            │
│                                     │
│  [📷 Open Camera]                   │
│                                     │
│  ─────── OR ───────                 │
│                                     │
│  Paste code from old device:        │
│  ┌─────────────────────────────┐    │  ← NEW!
│  │                             │    │
│  └─────────────────────────────┘    │
│  [Submit]                           │
└─────────────────────────────────────┘
```

Безопасность не страдает — текст зашифрован ephemeral ключом.

### 2. SD карта и Secure Delete — ACCEPT RISK 🟡

Gemini прав про wear leveling. Но:
- LUKS — overkill для v1
- Для защиты от гопников/воров текущий подход работает
- Восстановление требует лаборатории и выпаивания чипов

**Решение:** Документируем в THREAT_MODEL.md как known limitation. Для v2 можно добавить LUKS.

### 3. OOM и большие файлы — УЖЕ ЕСТЬ, НО УТОЧНИМ ✅

В спеке уже есть `io.Copy`, но добавим явно:
- `io.LimitReader` для защиты от переполнения диска
- Проверка свободного места перед upload
- Никаких tmpfs для файлов

### 4. Time Drift — НУЖЕН ФИКС 🔴

Реальная проблема! Дрифт времени может ломать auth и expires_at.

**Фикс:** Клиент хранит `time_delta` и использует его

```dart
// При auth_success:
final serverTime = response.serverTime;
final localTime = DateTime.now().millisecondsSinceEpoch ~/ 1000;
final timeDelta = serverTime - localTime;  // сохраняем

// При отправке сообщений:
final adjustedTimestamp = localTime + timeDelta;
```

## 5. Time Sync

```
PROBLEM:
├── Orange Pi may drift without NTP
├── Phone time may differ from server
└── expires_at / created_at may be invalid

SOLUTION:

Server auth_success:
{
  "server_time": 1699999999,
  ...
}

Client stores:
time_delta = server_time - local_time

Client uses for all timestamps:
adjusted_time = local_time + time_delta

Периодическая ресинхронизация:
├── При каждом reconnect
└── Каждые 6 часов (ping-pong с timestamp)
```

## 6. File Upload Protection

```go
// Проверка места на диске
func hasEnoughSpace(required int64) bool {
    var stat syscall.Statfs_t
    syscall.Statfs("/var/lib/homelan", &stat)
    available := stat.Bavail * uint64(stat.Bsize)
    return int64(available) > required + 100*1024*1024  // +100MB buffer
}

// Upload handler
func handleUpload(w http.ResponseWriter, r *http.Request) {
    // 1. Limit request size
    r.Body = http.MaxBytesReader(w, r.Body, maxFileSize)
    
    // 2. Check disk space
    if !hasEnoughSpace(r.ContentLength) {
        http.Error(w, "Insufficient disk space", 507)
        return
    }
    
    // 3. Stream directly to file (NO RAM buffering)
    dst, _ := os.Create(storagePath)
    defer dst.Close()
    
    // 4. LimitReader as additional protection
    limited := io.LimitReader(r.Body, maxFileSize)
    written, err := io.Copy(dst, limited)
    
    // 5. Verify size
    if written != expectedSize {
        os.Remove(storagePath)
        http.Error(w, "Size mismatch", 400)
        return
    }
}
```

## 7. Panic Script (FINAL)

```bash
#!/bin/bash
# /opt/homelan/panic.sh

DB="/var/lib/homelan/messages.db"
FILES="/var/lib/homelan/files"

# Kill server
pkill -9 homelan-server 2>/dev/null || true

# Sync filesystem
sync

# DELETE WAL AND SHM FIRST
rm -f "${DB}-wal" "${DB}-shm"

# Overwrite DB header (4KB = SQLCipher header)
dd if=/dev/urandom of="$DB" bs=4096 count=1 conv=notrunc 2>/dev/null

# Overwrite first 4KB of each file (optional, paranoid mode)
# find "$FILES" -type f -exec sh -c 'dd if=/dev/urandom of="$1" bs=4096 count=1 conv=notrunc 2>/dev/null' _ {} \;

# Sync
sync

# Drop caches
echo 3 > /proc/sys/vm/drop_caches 2>/dev/null || true

# Clear tmpfs
rm -rf /dev/shm/homelan/* 2>/dev/null || true

# Log
logger -t "HOMELAN_PANIC" "Wipe complete"
```

## 8. Dead Man's Switch (FINAL)

```go
func (s *Server) deadManSwitchLoop() {
    ticker := time.NewTicker(1 * time.Hour)
    for range ticker.C {
        // Validate system time (Orange Pi has no RTC battery)
        if time.Now().Year() < 2024 {
            log.Warn("Invalid system time, skipping dead man's switch")
            continue
        }

        admin, _ := s.db.GetAdmin()
        if admin == nil {
            continue
        }

        days := time.Since(time.Unix(admin.LastSeen, 0)).Hours() / 24
        if days > float64(s.config.DeadManSwitch.TimeoutDays) {
            s.triggerPanicWipe()
        }
    }
}
```
