# 🏠 HomeLAN Messenger v2.3 FINAL

**Хардкорный приватный self-hosted мессенджер для домашней локальной сети (LAN)**

---

## ⚡ О проекте

**HomeLAN Messenger** — это защищенная автономная система обмена сообщениями и файлами, созданная для работы в закрытой домашней локальной сети без подключения к интернету, серверов-посредников или внешних облаков. 

Система рассчитана на **2 пользователей** и **до 4 устройств** (ПК на Windows и смартфоны на Android) и оптимизирована для работы на микрокомпьютерах уровня **Orange Pi Zero 3** (2GB RAM) или любых Linux/Windows серверах в LAN.

---

## 🛡️ Ключевые фичи безопасности (v2.3 FINAL)

* **Сквозное E2E-шифрование:** Все сообщения, вложения и превью шифруются на устройствах по стандарту **XChaCha20-Poly1305** с обменом ключами по протоколу **ECDH X25519** (через `libsodium`).
* **Аппаратный ключ (USB Master Key):** Сервер проверяет наличие авторизованной USB-флешки каждые 5 секунд. Если вытащить флешку — запускается мгновенное уничтожение базы данных и файлов.
* **Пароль принуждения (Duress Password):** Поддержка специального пароля в `config.yaml`. При его вводе на экране авторизации сервер имитирует ошибку входа, а в фоне выполняет экстренное затирание данных.
* **Переключатель мертвеца (Dead Man's Switch):** Фоновый монитор сервера автоматически уничтожит все зашифрованные архивы, если администратор не появлялся в сети более 30 дней (с защитой от сброса часов на Orange Pi без RTC).
* **Безопасная привязка устройств (Device Linking):** 2-QR эфемеровый обмен ключами с поддержкой **Text Fallback** (для стационарных компьютеров без веб-камеры).
* **Защита от OOM и переполнения диска:** Стриминговая загрузка файлов через `io.Copy`, ограничение буфера RAM до 32 МБ и предварительная проверка свободного места.
* **Синхронизация часов в LAN (Time Delta Sync):** Алгоритм клиентской синхронизации времени компенсирует дрифт часов на устройствах без использования внешних NTP-серверов.

## ⚡ Быстрый старт

### 1. Запуск сервера
```bash
# 1. Перейдите в папку сервера
cd homelan-server

# 2. Инициализируйте USB Master Key на вставленную флешку
./homelan-server-arm64 --init-usb

# 3. Запустите сервер (прослушивает 0.0.0.0:8080)
./homelan-server-arm64
```

### 2. Подключение клиента
1. Установите APK (`app-release.apk`) на смартфон или запустите Windows-клиент.
2. Введите адрес сервера: `http://192.168.1.100:8080` (укажите IP вашего сервера в LAN).
3. Пройдите регистрацию первого пользователя (автоматически получает права Администратора).
4. Зарегистрируйте второго пользователя на другом устройстве и общайтесь в защищенном режиме!
